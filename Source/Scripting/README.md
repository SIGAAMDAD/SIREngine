# Scripting

This system owns native/managed script bridges, Mono embedding, C# assembly loading, lifetime/GC integration, serialization and runtime script execution.

`SIR::MonoRuntime` can be enabled using a compatible Mono development SDK. It is currently an SDK dependency target, not a working C# scripting host.

See [managed scripting architecture](../../Docs/Architecture/14-managed-scripting.md).
