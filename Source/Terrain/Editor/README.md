# Terrain authoring

**Classification:** built-in Terrain editor tooling.
**Status:** integration pending.

Terrain-specific brushes, erosion, painting, region import/export, material editing and save/reload integration live here beside the owning Terrain runtime system. General inspector, scene and editor infrastructure belongs in `Source/Editor/`.

See [Terrain milestone](../../../Docs/Milestones/03-Terrain.md).
