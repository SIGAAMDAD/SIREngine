# Editor

SIREngine's integrated scene editor, inspectors, import tools, script tooling and asset-authoring workflows belong here. Individual subsystem-specific tools remain close to their owner where appropriate, such as `Source/Terrain/Editor/`.

The original editor functionality must be ported and verified before it is treated as a working SIREngine editor. See [milestone 2](../../Docs/Milestones/02-Godot-Startup-Editor.md).
