# Security policy

Do not post exploitable engine vulnerabilities, secret material or proof-of-concept payloads in public issues. Use GitHub's private vulnerability reporting / security advisory contact for this repository when enabled. If unavailable, contact the repository maintainer through a private channel.

When reporting, include affected commit, platforms, reproduction conditions and impact. SIREngine is an experimental engine integration branch; only officially tagged releases can be considered for supported security fixes after a release policy has been published.
