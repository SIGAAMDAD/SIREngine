# Support and technical discussions

For build or compiler failures open a **bug report** with the exact commit SHA, OS, compiler, generator, CMake/SCons versions, the first actionable error and commands used. For design changes open a feature/architecture request linked to the relevant `docs/architecture` contract.

For user-facing questions or non-bug conversations use the repository Discussions section if available. The new foundation branch is not yet a production SIREngine release.
