# Terrain editor

**Kind:** built-in SIREngine editor functionality.
**Status:** source boundary established; editor integration pending.

Terrain authoring includes brushes, painting, erosion, material management, region import/export, selection, and save/reload. The editor consumes Terrain runtime interfaces without placing editor GUI code in the runtime subsystem.

See [Terrain milestone](../../../../Docs/Milestones/03-Terrain.md).
