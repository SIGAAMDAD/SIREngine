# Community conduct

Discussion and review are technical and evidence-driven. Critique designs, code and measurements directly, including identifying defective implementations, missing tests or unjustified performance claims. Do not harass, threaten, dox, discriminate against or deliberately derail other participants.

Project maintainers may moderate or close threads that violate these rules. Use GitHub Issues/Discussions for technical questions, and private GitHub security reporting for security-sensitive findings when available.
